# 模型与十趟规则

所有时间单位秒，质量 kg，角度度；这里只是街机模型，不模拟真实电梯安全系统。

质量 M 为人和货物质量总和。横向站位 x=-1/0/1（单位为轿厢半宽），双格取两格中点。偏载 b=Σ(m*x)/M，空载为0。平衡不会抵消超载。

超载比例 o=max(0,(M-300)/150)。大于450禁止关门发车；营业结束时若仍超重，按最后上客顺序安全下客至合法质量。行进时间=基础距离时间*(1+1.2o)。负荷以6o点/秒增长，无超载则每秒恢复8点，100点安全停靠。

扶手 correction 以每秒3倍差值追踪输入*0.24；松手目标0。侧倾目标=(b+correction)*13*高重心系数+可见启停/接缝扰动，钳制±17°。有旅行客系数1.18；教练质量占比使扰动最多减少50%。启停扰动使用有界1.1°正弦包络；关卡接缝用1.5秒正弦脉冲、提前1.2秒文字预告，方向由记录种子确定。θ''=14*(目标-θ)-7*θ'，固定1/60秒积分。7°警戒，11°危险持续2.5秒触发安全停靠；低于危险时危险累计每秒恢复2秒。每帧追赶最多0.25秒，后台自动暂停。

票款仅在送达后结算。全程警戒累计≤0.6秒奖励5；关卡截止时间内完成（包含上客、等待、关门、行进、停靠、下客）获得准时奖；准时且有外卖员额外3。正常维护费ceil(8o)；应急仅收floor(票款*0.5)、无奖励、维护12，额外安全停靠4秒。空载没有票款或奖励。一趟只结算一次。

关门3秒，重新开门1.5秒，到站减速0.8秒、开门1秒、下客1.2秒。队列最多5人，按关卡配置出现，满队列丢弃该次到达；不积压。关门最多一次额外来客；重开不刷新。候梯离开无收入也不倒扣历史收入。营业270秒或十趟结束，以先到为准，当前运输可超出营业时间安全完成。
