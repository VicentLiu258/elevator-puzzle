# 3D 玩偶改版记录

日期：2026-10-28。仍基于 Cocos Creator 3.8.8 的单趟玩法，不升级引擎，不更改旧 React 工程或线上域名。

## 实际制作

- Blender 5.2.2 Python 生成原创实体玩偶模型：学生、上班族、外卖员、旅行客、搬家客、健身教练。使用同一基础比例，以衣服、发型、眼镜及道具区分。搪胶皮肤、哑光衣服、橡胶鞋底和金属配件由 Cocos 标准 PBR 材质表现。
- 剖面轿厢包含门框、楼层灯、黄铜扶手、墙板、地板、活动门；搬家纸箱独立占第二格。前门为剖视门，关闭时保留对人物的可见性。
- 真实 FBX 网格通过 Creator 资源导入成为 Prefab；未用背景图片冒充 3D。固定正面略俯视镜头，所有逻辑仍来自原规则模型。
- 新界面包含顶部计时/票款/趟数、世界空间站位、候梯乘客信息、载重/偏载指示及底部操作。角色有轻微待机动作，上客/换位使用平滑位置过渡，行进时随侧倾摇晃。
- 准备期间不计时；首次上客或关门后开始营业。点选与直接拖动玩偶两种操作并存。

## 文件

- `art/generate_diorama.py`：可重复生成脚本（`--sample` 只生成学生、轿厢、门，用于导入验证）。
- `art/elevator-dolls.blend`：实际生成的可编辑 Blender 工程。未显示的角色模型在场景中保留，名称与角色类型一致。
- `art/asset-manifest.json`：模型来源、三角面数和 Blender 版本。
- `cocos/assets/resources/models/*.fbx`：九份实际导入模型。角色约 1.7–2.0 万三角面/个，轿厢 8204 三角面。
- `cocos/assets/scripts/Diorama.ts`：固定镜头、材质、灯光、角色节点和动画显示。运行时按材质名统一颜色与粗糙度。
- `cocos/assets/scripts/PrototypeUI.ts`：新版界面和屏幕投影点击/拖动。
- `docs/3d-gameplay.png`：浏览器真实游戏截图；`art/style-preview.png` 是 Blender 样例渲染，二者区别明确。

## 实际验证

- Creator 3.8.8 成功导入 FBX 并完成 Web Mobile 构建；最终产物仍为 `cocos/build/web/`。
- TypeScript 项目检查通过（使用 Creator 附带编译器，`--noEmit --skipLibCheck`）。
- `tests/run-core-tests.sh` 通过；核心计重、占位、关门、偏载、暂停、结算规则测试保持有效。
- 在桌面浏览器的竖向页面实测：点选学生上客后载重 45kg、票款 8；直接拖动候梯玩偶上客；将外卖员从左侧换到右侧后偏载方向变化；关门后重开；运输完成后结算票款 23、奖励 5、维护 0、净收入 28；重开、再次上客和暂停。
- 多人画面：学生和上班族同车，显示总重 110kg、预计票款 20，场景与数据一致。

未验证：真实手机触屏、极窄/横屏设备、低端 GPU 性能、双指压力测试。尚无骨骼动画或照片级人类皮肤；当前是原创三维搪胶玩偶风格。十趟经营、美术完整验收和正式发布仍待后续阶段。
