# 乘客避让与先下后上（2026-10-28）

在现有四肢动画上新增纯TypeScript行人路径模块 `core/traffic.ts`，不依赖刚体引擎。每位乘客使用0.82世界单位的中心安全间距，路径以0.14网格搜索，所有移动线段再次进行连续距离检查，不能只检查终点。遇到站立乘客绕行；目标被占用则等待，不强推或穿过对方。

候梯位置固定，离开后留下空位，新乘客补空位；队列不再整排重排。新乘客从右侧分隔的出生点入场，下客从左侧离开。通行由单一行走预约调度，其他人保持站位等待；下客优先、上客其次、新到队列最后。门口及狭窄轿厢避免多人对向抢行。满员下客按靠近门口者先行。站位调整同样经过避让规划，不改变逻辑占位。

关门等待上客站稳及已有下客走完。下客阶段延续至出口动作完成，再结算并进入下一趟；等待与行走继续消耗营业时间，不是免费暂停。暂停和切后台冻结动作。重开一局清理旧角色和行走预约，防止残留路径阻塞。
